# 材料备货助手 — 新人上手

> 面向**第一次接触这个模组**的玩家。看完这一篇就能用起来。
> 需要先会用 [Litematica（投影）](https://modrinth.com/mod/litematica) —— 本模组是它的配套工具，不是替代品。

---

## 一句话说明它是干什么的

**照着投影盖房子最烦的是"备料"**：跑遍仓库数还差多少铁块、白色混凝土、红石元件……

这个模组做三件事：

1. **读投影** → 自动列出这个投影需要哪些材料、各要多少（按原版分类整理）
2. **数仓库** → 框选你的仓库箱子，扫描出"已经有多少"
3. **算差额** → 直接告诉你**还缺多少**，缺的还能进合成计算器，算出要挖多少矿、烧多少石头

## 二、安装

### 前置要求

| 项目 | 要求 | 说明 |
|---|---|---|
| Minecraft | **1.21 ~ 1.21.1** | 更高版本不支持 |
| Java | **21** | 游戏本体要求 |
| Fabric Loader | ≥ 0.15.11 | |
| **Fabric API** | 任意 | 必需 |
| **Litematica（投影）** | ≥ **0.19.54** | 必需，本模组要读投影文件 |
| **MaLiLib** | ≥ **0.21.7** | 必需，Litematica 的依赖 |

> ⚠️ 版本号别填错：Litematica **0.19.53 及以下**缺少本模组用到的一个接口，装了会在启动时被 Fabric 拒绝加载（会明确提示版本不满足，不会崩游戏）。

### 步骤

1. 装好 **Fabric**（用你的启动器自带的 Fabric 安装功能，**不要**用官网的 Fabric Installer —— 它是给官方启动器做的，用 PCL2/HMCL 会报「找不到启动器配置文件」）
2. 把下面这些 jar 全部丢进 `.minecraft/mods/`：
   - `fabric-api`
   - `litematica`
   - `malilib`
   - **`materialstock`**（本模组）
3. 启动游戏，进任意世界

## 三、三个必须先理解的概念

新手最容易卡在这里，我见过有人用了很久还没分清这两个区。

### 备货区 = 「我已经有的东西」

- 你把**装材料的箱子**框起来，告诉模组"这些是我的库存"
- 扫描后，模组会数出每个物品有多少
- 这个数字**会参与**"还缺多少"的计算

### 材料区 = 「另一份独立的库存」

- 用途和备货区类似，但**故意分开统计**
- 它的数量**不参与**"还缺多少"的计算
- 适合：把"待用材料"和"长期储备"分开管；或者临时框一块地方单独数数

> **记忆方法**：算差额时**只认备货区**。材料区是另一本账。

### 投影 = 你要盖的东西

材料清单就是"盖这个投影需要什么"。

## 四、第一次使用（推荐流程）

以"我要盖一个熔炉组"为例。

### 第 1 步：看一眼需要什么（只读，不改任何东西）

1. 按 **`Y`** 打开模组主界面
2. 「搜索投影」框里输入文件名关键字
3. 点列表里的投影名 → 进入**材料清单**

你会看到按原版分类排好的清单：

```
▼ 染色方块（9 种，共 36817 个）
   白色混凝土 × 25×64+32   已有 0 个 / 缺 25×64+32
   白色染色玻璃 × 17盒+580  已有 0 个 / 缺 17盒+580
▼ 红石与元件（22 种，共 30677 个）
   ...
合计：需要 103703 · 备货区已有 0 · 缺少 103703
```

4. 「数量倍数」填 `2` → 需要量整体翻倍（盖两份）

**这一步不需要框选任何东西，纯看。**

### 第 2 步：告诉模组"我的仓库在哪"

1. 到「备货区」页
2. 在游戏里**对准箱子堆的一个角**，按 **`K`**（默认键），提示会告诉你"已选点"
3. 走到**对角**，再按一次 `K`
4. 回到界面，填个名字（比如 `主仓库`），点「**保存为备货区**」
5. 点「**扫描备货区**」

扫描完底部会显示：

```
备货区缓存：4 个容器 · 共 72 种物品 / 46584 个
```

### 第 3 步：看还缺多少

回到「材料清单」，现在的"已有"和"缺少"就是真实差额了。

- 想只看**缺的**：搜索框输入 `缺失`（或拼音 `qs`、`缺`）
- 想只看**已凑齐的**：输入 `完成`（或 `wc`、`收集`）
- 想**忽略**某个材料（比如你不想备它）：选中该行 → 点 `[忽略]`

> 搜索框支持 **中文 / ID / 全拼 / 首字母**。例如"白色混凝土"可以打 `bai`、`bshnt`、`white_concrete`。

### 第 4 步（可选）：算出要挖多少矿

清单里某个材料缺很多时，可以算出它的**基础材料**：

1. 选中该行 → 点 `[计算配方]`（或直接到「合成计算器」页搜它）
2. 计算器会显示它的合成配方，以及**逐层展开**的直接原料
3. 材料行点「**子合成**」可继续往下展开（如 铁块 → 铁锭 → 铁粒）

「对比差异」按钮更省事：**一键把清单里所有"缺失且有配方"的物品批量送进计算器**。

## 五、常用快捷键

进游戏后在 `选项 → 控制 → 按键绑定` 里可以改。

| 按键 | 默认 | 作用 |
|---|---|---|
| 打开主界面 | **Y** | 打开本模组 |
| 框选角点 | **K** | 对准方块按一次记一个角点，按两次记一对 |
| 材料区高亮开关 | **H** | 显示/隐藏材料区在世界里的范围框 |

> 界面底部会**实时**显示你当前的键位，改键后立刻生效。

## 六、容易踩的坑

### 1. 用了官网的 Fabric Installer

PCL2 / HMCL 用户请用**启动器自带的** Fabric 安装功能。
官网那个 Installer 是给**官方启动器**写的，它会去读 `launcher_profiles.json`，第三方启动器没有那个文件，就会报「找不到启动器配置文件 profile.json」。

### 2. 把「材料区」当「备货区」用

算差额只认**备货区**。如果你把材料都框成"材料区"，那"已有"永远是 0，会显示"缺全部"。

### 3. 投影文件要放在 Litematica 的目录里

本模组只列出 Litematica 认得的投影文件（`.litematic` 等）。
路径是 `schematics/` 文件夹（在游戏目录下）。

### 4. 第一次进世界要重扫

容器数据会保存在配置里，但**换了世界/模型/位置**之后建议重扫一次。
扫描时会自动剔除"已经被挖掉或移出选区"的箱子，所以重扫是安全的。

### 5. 「追踪」只高亮材料区的箱子

在材料行/材料区明细点 `[追踪]`，会在世界上用黄框标出装有该物品的箱子 —— 但**只标材料区**里的箱子（备货区的不标）。这是刻意设计。

## 七、它和 Litematica 自带材料清单的区别

| | Litematica 自带 | 本模组 |
|---|---|---|
| 列出投影所需材料 | ✅ | ✅ |
| **对比你仓库里的实际库存** | ❌ | ✅ |
| **算"还缺多少"** | ❌ | ✅ |
| 合成配方推导（铁块→铁锭→…） | ❌ | ✅ |
| 按原版标签分类 + 自定义分类 | ❌ | ✅ |
| 在世界里高亮"这个材料在哪个箱子" | ❌ | ✅ |
| 搜索支持拼音 | ❌ | ✅ |

简单说：**Litematica 告诉你"要什么"，这个模组告诉你"还差什么"。**

## 八、界面速查

打开主界面后，顶部四个页签：

| 页签 | 干什么 |
|---|---|
| **材料清单** | 看投影需要什么、还缺什么 |
| **合成计算器** | 算某个东西要用多少基础材料 |
| **备货区** | 框选仓库、扫描库存 |
| **材料区** | 另一份独立库存 |

> 鼠标**悬停**在页签上会弹出提示，说明该页功能与去向。

其余界面（分类管理、各明细页）都有 `← 返回` 或「Esc / 右键 返回」。
