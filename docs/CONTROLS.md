# 材料备货助手 — 界面控件与快捷键对照

> 本表按**代码实际行为**整理（`src/main/java/com/materialstock/gui/`），不是照截图猜的。
> 快捷键可在 `游戏菜单 → 选项 → 控制 → 按键绑定` 修改，界面底部提示会**实时**显示新键位。

---

## 一、全局快捷键

| 按键 | 默认 | 功能 |
|---|---|---|
| **打开主界面** | `Y` | 在主世界/任何界面外按，打开「材料清单」主界面 |
| **框选角点** | `K` | 对准方块按一次记一个角点；**按两次**记下两个对角点。选好后到备货区/材料区页面点「保存为…」 |
| **材料区高亮开关** | `H` | 切换世界中**材料区范围框**的显示/隐藏（材料区默认不显示框）。界面上的「高亮:开/关」按钮同效 |
| **扫描备货区** | 未绑定 | 一键扫描所有备货区（等同备货区页的「扫描备货区」） |
| **打开备货区界面** | 未绑定 | 直接打开「备货区」页 |

> 界面底部会显示当前绑定：`快捷键：[Y] 主界面 · [G] 框选角点 · [H] 材料区高亮开关`
> （`G`/`K` 取决于你的实际绑定）

---

## 二、顶部页签（四个界面共有）

鼠标**悬停**会弹出提示，说明该页做什么、点下去会跳到哪。

| 页签 | 功能 |
|---|---|
| **材料清单** | 打开投影文件，按原版标签分类列出需要的材料，并对比备货区已有数量 |
| **合成计算器** | 输入成品与数量，自动推导基础材料与合成配方，显示已有/还缺多少 |
| **备货区** | 框选备货区并扫描，统计已备好的材料数量（作为「已有」） |
| **材料区** | 框选材料区并扫描，作为**独立**的一份库存统计；支持展开明细与追踪高亮 |

## 三、材料清单 — 列表页

| 控件 | 功能 |
|---|---|
| **搜索投影**（输入框） | 按关键字过滤投影文件列表 |
| **刷新列表** | 重新扫描投影目录，刷新文件列表 |
| **清除缓存** | 清除全部材料缓存，**并关闭信息浮窗**（HUD） |
| **分类管理** | 打开「分类管理」界面，自定义大类/小类归属 |
| **已加载投影行** | 点击进入详情页查看材料清单 |
| **［再次加载］** | 重新解析该投影（文件改动后刷新数量） |
| **［清除缓存］** | 只清除**这一个**投影的缓存 |
| **打开按键设置** | 直接跳转到游戏的按键绑定设置页 |

## 四、材料清单 — 详情页

| 控件 | 功能 |
|---|---|
| **← 返回** | 回到投影列表页 |
| **搜索**（输入框） | 过滤材料。支持**中文名 / ID / 全拼 / 首字母**，以及**状态词**：<br>`忽略`(`hl`/`hulve`) · `缺失`(`qs`/`que`/`缺`) · `完成`(`wc`/`收集`/`shouji`) |
| **数量倍数** | 把"需要量"整体乘以该系数（例如填 2 = 备两份） |
| **信息显示** | 开/关右下角**信息浮窗**（HUD）：显示未收集且未忽略的材料与数量 |
| **对比差异** | 扫描备货区并与需求对比，把**缺失且有配方**的物品**批量加入合成计算器** |
| **排列：类别 / 升序 / 倒序** | 循环切换排序方式（按大类小类 / 按需求量升序 / 降序） |
| **恢复全部忽略** | 取消所有「忽略」标记 |
| **大类/小类标题** | 点击折叠或展开 |
| **⟨行首勾选框⟩** | 勾选/取消勾选单项材料 |
| **［忽略］/［恢复忽略］** | 选中某行后在行内出现：忽略的材料不进信息浮窗（详情页仍显示） |
| **［计算配方］** | 选中某行后在行内出现：跳到合成计算器并带入该物品 |
| **［追踪］/［取消追踪］** | 选中某行后在行内出现：在世界上高亮装有该物品的箱子 |

## 五、合成计算器

| 控件 | 功能 |
|---|---|
| **搜索（支持拼音、中文、ID）** | 搜成品。药水会**展开成变体**（水瓶 / 粗制的药水 / 隐身药水 / 喷溅型…） |
| **清空选择** | 清空当前所有选择/输入 |
| **收藏：N 项**（文本框） | 点击展开收藏下拉；点其中一项即把该物品加为成品 |
| **删除收藏** | 删除收藏：先展开收藏列表点选一项，再点此按钮删除 |
| **保留搜索：关/开** | 切换：添加成品后**是否保留**搜索框内容 |
| **退出保留：开/关** | 切换：退出游戏后**是否保留**当前计算器的成品选择 |
| **候选行**（点击） | 添加为成品（只点物品图标+名字区才触发） |
| **⟨成品行勾选框⟩** | 勾选/取消该成品参与计算 |
| **配方 i/N·类型** | 循环切换产物的配方；类型会显示 **合成 / 熔炼 / 切石 / 酿造** |
| **［锁定］/［解锁］** | 锁定该成品，清空选择时不被清掉 |
| **收藏**（成品行） | 把该成品加入收藏列表 |
| **删除**（成品行） | 从成品列表移除 |
| **数量**（成品行输入框） | 该成品的目标数量 |
| **材料标题后的 [展开]** | 打开**材料明细全屏界面**：可搜索、可逐项 `[追踪]`，与材料区的展开功能一致 |
| **⟨材料行勾选框⟩** | 勾选/取消该材料（未勾选显示"（未勾选）"） |
| **数量框（材料行）** | 修改顶层材料的数量，支持分数（如 `1/9`）；子行只读，随父级自动换算 |
| **子合成 / 收起** | 展开/收起该材料的**直接原料**（可逐层展开，上限 4 层） |
| **清除**（材料行） | 清空该材料的数量 |
| **追踪 / 取消追踪**（材料行） | 在世界上高亮装有该材料的**材料区**箱子 |

## 六、备货区

| 控件 | 功能 |
|---|---|
| **区域名称**（输入框） | 给即将保存的选区起名 |
| **保存为备货区** | 把当前框选的两个角点保存为备货区 |
| **清除选区** | 放弃当前未保存的框选（两个角点） |
| **扫描备货区** | 扫描所有备货区容器，统计物品数量，作为「已有」 |
| **清除全部** | 删除**所有未锁定**的备货区，**并清空容器缓存**（锁定的保留） |
| **⟨选区行⟩ ［锁定］/［解锁］** | 锁定后「清除全部」不会删它 |
| **［坐标(改)］** | 进入坐标编辑：可直接输入 x1/y1/z1/x2/y2/z2 |
| **［确定］**（坐标编辑时） | 应用改后的坐标（自动纠正大小顺序） |
| **［取消］**（坐标编辑时） | 放弃坐标修改 |
| **［改名］** | 重命名该备货区 |
| **［确定］**（改名时） | 应用新名称 |
| **［删除］** | 删除该备货区，并移除其区域内的容器缓存 |
| **物品明细行** | 显示备货区物品与数量，滚轮翻页 |
| **备货区缓存：N 个容器…** | 底部统计（**只含备货区**，材料区不计入） |

## 七、材料区

| 控件 | 功能 |
|---|---|
| **高亮：开/关** | 切换世界中材料区范围框的显示（等同按 `H`） |
| **区域名称**（输入框） | 给即将保存的选区起名 |
| **保存为材料区** | 把当前框选保存为材料区 |
| **清除选区** | 放弃当前未保存的框选 |
| **扫描材料区** | 扫描所有材料区容器，作为**独立**库统计 |
| **清除全部** | 删除所有**未锁定**的材料区及其容器明细（锁定的保留） |
| **⟨选区行⟩ ［锁定］/［解锁］** | 锁定后「清除全部」不会删它 |
| **［坐标(改)］/［确定］/［取消］** | 同备货区，编辑该材料区的坐标 |
| **［改名］** | 重命名该材料区 |
| **［删除］** | 删除该材料区，并把物品从汇总中扣除 |
| **材料区材料：共 N 种** | 材料区物品列表（滚轮翻页） |
| **［展开］** | 打开**材料区物品明细**全屏界面 |
| **材料区缓存：N 个容器…** | 底部统计（**独立统计，不与备货区混合**） |

|---|---|

## 八、分类管理

| 控件 | 功能 |
|---|---|
| **搜索物品** | 搜索要归类的物品（支持**中文 / 拼音 / ID**） |
| **← 返回** | 回到材料清单 |
| **新建大类** | 用输入框的名字新建一个大类 |
| **删除大类** | 删除当前选中的大类（「其他」是兜底类，不可删除） |
| **新建小类** | 在选中的大类下新建小类 |
| **删除小类** | 删除当前选中的小类 |

| **⟨右侧物品列表⟩** | 点物品选中，**再点左侧分类**即把该物品放入该分类 |

## 九、状态提示中的关键名词

| 名词 | 含义 |
|---|---|
| **需要** | 当前投影/成品算出的需求量 |
| **已有** | **备货区**扫描到的数量（材料区不计入） |
| **缺少** | 需要 − 已有（不足部分） |
| **已收集 N 种** | 已有 ≥ 需要的物品种数 |
| **已忽略 N 种** | 被标为忽略的物品种数 |
| **锁定** | 清除全部时保留 |
| **追踪** | 在世界上用黄色框高亮装有该物品的**材料区**箱子（重启后仍有效） |

## 十、两个概念的区别（容易混）

| | 备货区 | 材料区 |
|---|---|---|
| 用途 | 已备好的材料，作为「已有」参与对比 | 另一份独立库 |
| 是否计入「已有」 | ✅ 是 | ❌ 否（独立统计） |
| 默认显示范围框 | 显示 | **不显示**（按 `H` 才显示） |
| 容器数统计 | 只算备货区 | 只算材料区 |
| 与追踪的关系 | — | 追踪**只高亮材料区**的箱子 |
